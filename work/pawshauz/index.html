Overview

Customers, merchants and vets all need it to work at once.

Pawshauz connects pet owners with the businesses and vets that look after their pets. The customer app is for shopping, finding vets and asking PawsAI; the merchant app runs a pet business, and vets use it for consultations.

My role

I was the sole mobile engineer at Jamforte Technologies. Architecture, features and releases for both apps were mine, built against the company’s backend.

Engineering challenges

  1. 01

    An AI assistant that behaves like a product feature

    PawsAI streams responses letter by letter, persists the session so conversations survive, and exits cleanly when a user leaves mid-response.

  2. 02

    Inventory that stays fresh without hammering the API

    The merchant dashboard pairs an earnings chart and the order pipeline with inventory backed by TTL caching.

  3. 03

    Vets who work across clinics

    Consultation requests and emergency alerts inside the merchant app, with switching between clinics.

  4. 04

    Chat that feels instant

    Optimistic UI so messages appear immediately, with multi-image bubbles.

  5. 05

    Payments and releases

    Flutterwave subscriptions, wallet top-up and withdrawal, and the release pipeline from code signing to TestFlight and the Play Store.
